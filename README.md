# 👑 Dethrone

**Една песен, целият свят слуша.**

На сайта върви само една песен, на повтор, за всички. Всеки може да прати песен на дуел срещу тази на трона. Двете се изправят една срещу друга, слушателите гласуват, и печели по-харесваната. Тронът се печели с музика, не с пари.

## Какво има в прототипа

- **Трон** с таймер колко време царува песента. Музиката тръгва сама, когато отвориш сайта, и всички слушат едно и също място едновременно.
- **Без въведения и истории**: за песните от YouTube сайтът сам открива къде почва и свършва музиката чрез [SponsorBlock](https://sponsor.ajay.app) (общностна база с отбелязани части без музика в клиповете) и прескача частите без музика. Общото слушане се брои по музиката, така че щом песента седне на трона, всички я чуват от реалното ѝ начало.
- **Ръчно начало и край**: ако за клипа няма данни, този, който го е добавил, задава началото и края с бутона до плейъра („Сега“ взима текущия момент). Работи и `?t=` в YouTube линка.
- **Дуели на живо**: шампион срещу предизвикател, гласуване, обратно броене, резултатите се обновяват веднага при всички.
- **Опашка** от чакащи предизвикатели.
- **Търсачка за песни**: търсиш по име на песен или изпълнител направо в сайта, чуваш резултата и го добавяш с едно натискане. Името и изпълнителят се почистват от „(Official Video)“ и подобни. Линк от YouTube също може да се постави.
- **Качване на оригинална музика** от артисти (mp3, m4a, wav, ogg).
- **Бакшиши** за нови артисти: готови суми или собствена (1–50 €), съобщение до артиста, лента с последни бакшиши. В **тестов режим**, не се теглят реални пари.
- **Страница на артиста**: песни, победи, събрани бакшиши, класация на феновете.
- **🏅 Най-голям фен**: значка за фена с най-много точки за даден артист. 1 точка за всеки глас за негова песен (отчита се след края на дуела), 3 точки за всяко евро бакшиш. Значката се дава само на фенове с име.
- **Моите значки**: бутонът 🏅 горе показва артистите, които подкрепяш, и къде си най-голям фен.
- **Зала на славата** (най-дълги царувания), **Ловци на таланти** (кой праща песни, които свалят трона), **последни дуели**.

## Пускане локално

Трябва ти само [Node.js](https://nodejs.org) версия 18 или по-нова. Няма външни пакети, не е нужно `npm install`.

```bash
npm start
```

Отвори **http://localhost:3000**.

За по-бързи тестове (дуел от 30 секунди, пауза 10 секунди):

```bash
npm run dev
```

За да тестваш гласуването от „няколко души“, отвори сайта в нормален прозорец и в прозорец Incognito. Всеки браузър е отделен гласоподавател.

### Търсене в YouTube

За да търсиш песни директно в сайта (без да копираш линкове), трябва безплатен ключ за YouTube Data API. Прави се веднъж, за около 5 минути:

1. Отвори [Google Cloud Console](https://console.cloud.google.com/) и влез с Google акаунт.
2. Горе до логото избери проект, после **New Project**, дай му име (например `Dethrone`) и го създай.
3. От менюто: **APIs & Services → Library**. Потърси **YouTube Data API v3** и натисни **Enable**.
4. От менюто: **APIs & Services → Credentials → Create credentials → API key**. Копирай ключа.
5. По желание, но е препоръчително: натисни **Edit API key**, в **API restrictions** избери **Restrict key** и отметни само **YouTube Data API v3**.
6. В папката на проекта направи файл `.env` от примера и сложи ключа:

   ```powershell
   Copy-Item .env.example .env
   notepad .env
   ```

   Редът трябва да изглежда така: `YOUTUBE_API_KEY=AIza...`
7. Рестартирай сървъра. В конзолата трябва да пише „Търсене в YouTube: включено“.

Файлът `.env` не се качва в GitHub, така че ключът остава само на твоя компютър.

Безплатният лимит е 10 000 единици на ден, а едно търсене струва 100, т.е. около 100 различни търсения на ден. Еднаквите търсения се пазят 12 часа и не се броят отново. Показват се само клипове, които позволяват пускане в други сайтове.

### Настройки

| Променлива | По подразбиране | Какво прави |
|---|---|---|
| `PORT` | `3000` | Порт на сървъра |
| `DUEL_SECONDS` | `120` | Колко трае един дуел |
| `BREAK_SECONDS` | `20` | Пауза между дуелите |
| `MAX_UPLOAD_MB` | `20` | Максимален размер на качен файл |
| `YOUTUBE_API_KEY` | (няма) | Ключ за търсенето в YouTube (виж по-горе) |

Пример: `DUEL_SECONDS=60 npm start`

### Изчистване на данните

```bash
npm run reset
```

Данните се пазят в `data/db.json`, качените песни в `uploads/`.

## Структура

```
server.js        сървър: API, логика на дуелите, живи обновления (SSE)
public/
  index.html     страницата
  style.css      дизайн
  app.js         плейър, дуели, библиотека, форми
data/            базата (създава се сама)
uploads/         качените песни
```

## Правила на дуела

1. Ако тронът е празен, първата пратена песен сяда директно на него.
2. Всяка следваща влиза в опашката. Когато няма активен дуел, първата в опашката предизвиква трона.
3. Дуелът трае `DUEL_SECONDS`. Всеки слушател има един глас (може да го смени).
4. Печели песента с повече гласове. **При равенство шампионът остава.**
5. След дуела има пауза `BREAK_SECONDS`, в която тронът свири, после започва следващият дуел.

## Известни ограничения

- Браузърите не позволяват звук, преди човек да е кликнал по страницата. Затова музиката тръгва без звук, а звукът се включва при първото кликване където и да е. Chrome позволява звук веднага на сайтове, които ползваш често.
- Някои YouTube видеа забраняват вграждане. Тогава излиза съобщение и трябва друга песен.
- На телефон YouTube спира, когато заключиш екрана. Качените оригинални песни продължават.
- Няма регистрация: гласоподавателят се разпознава по браузъра. За истински старт трябва вход с акаунт.
